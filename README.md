# Sales Forecast

End-to-end retail sales forecasting project for SuperKart, covering machine learning model development, evaluation, and deployment for outlet-level revenue prediction.

## Project contents

- `Full_Code_SuperKart_Model_Deployment_Notebook.ipynb` — full-code workflow for the SuperKart forecasting and deployment project.
- `Low_Code_SuperKart_Model_Deployment_Notebook.ipynb` — low-code version of the SuperKart deployment workflow.
- `SuperKart.csv` — dataset used by the SuperKart notebooks.
- `Case_Study_Introduction_to_Model_Deployment_Notebook.ipynb` — model deployment case-study notebook.
- `Case_Study_REST_API_and_Containerization_Notebook (1).ipynb` — REST API and containerization case-study notebook.
- `MLS2_Rental_Property_Price_Prediction_Frontend_BackendNotebook.ipynb` — frontend/backend deployment example for a rental-property price prediction use case.

## Topics demonstrated

- Data preprocessing and exploratory analysis
- Regression / sales forecasting workflows
- Model evaluation
- Model serialization and deployment
- REST API based inference
- Frontend/backend application patterns
- Hugging Face Spaces deployment workflows
- Containerization concepts

## Security note

Authentication tokens are intentionally omitted from the notebooks. Add your own credentials through environment variables or your deployment platform's secret-management feature rather than committing them to source control.
